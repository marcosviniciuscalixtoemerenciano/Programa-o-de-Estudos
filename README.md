# Programa-o-de-Estudos
Este projeto consiste em uma página web simples e estruturada desenvolvida para organizar e exibir uma rotina de estudos diária e semanal. Seu objetivo é fornecer ao estudante um guia visual claro sobre como dividir seu tempo entre teoria, prática, revisão e descanso, além de organizar a distribuição das matérias ao longo dos dias da semana.
